## 厂内只需运行

在原来的 Work3 仓库下用已配置的 P0 Python 环境运行。DRZERO_DIR 指向原来的 P0 目录；如 P0 曾用 OUT_ROOT 覆盖输出位置，请保留原值。

```bash
git fetch origin tag p0-retrieval-diag-r1
git checkout p0-retrieval-diag-r1
bash scripts/p0/run_retrieval_diag.sh
```

输入为 data/test.parquet 和 OUT_ROOT/eval/iter1、iter2、iter3 的原始评测 dump。默认 OUT_ROOT 为 DRZERO_DIR/work3_p0。脚本只读上述文件、使用 CPU，标注已附带，运行期间不访问网络。脚本不启模型、检索服务或 Ray，不清理进程，现有 Search-R1 7B 保活训练可以继续。输出在 OUT_ROOT/retrieval_diag 下。

- retrieval_diag_return.json 是需要贴回反馈的汇总，包含输入质量、判定、主要对照与来源哈希。
- retrieval_diag.json 保留完整分组和预算数据，留在厂内。
- 如果退出码为 2，仍贴汇总 JSON，其中有输入质量问题。如果脚本报错且没有新 JSON，贴报错末尾与这次运行的版本。遇到解析问题由家服修脚本。
