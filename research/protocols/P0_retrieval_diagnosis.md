# P0 离线检索诊断协议

冻结日期 2026-11-17。适用于 P0 的已保存评测轨迹，作为是否开展同前缀回放的诊断。正式 P0 PASS、P1 NO-GO 与 NCP/P2 的关闭决定沿用原协议。

## 输入与配对

- P0 第 1、2、3 轮评测 JSONL 和原始 data/test.parquet。第 1→3 轮为主对照，第 2→3 轮为定位用的辅助对照。HotpotQA 与 2Wiki 是支持证据主分析，另外两套多跳集只报答案字符串命中等探索统计。
- 按数据集与规范化问题哈希配对，重复问题从配对中剔除。支持标注另须与 P0 标准答案有交集。题目、答案、检索文本和标注均保留在执行侧。
- 公开标注来自同口径 FlashRAG dev 的 metadata.supporting_facts 与 metadata.context，参见数据目录 README。支持事实的标题与句号索引分别用来匹配文档标题与支持句。支持句使用标准化后的完整词序列，要求出现在同标题的检索正文；匹配失败包括切片、版本、改写或真正未取到。支持标题覆盖不能单独证明找齐事实。
- 桥接与答案证据使用保守的角色代理。HotpotQA 仅纳入 bridge 型，2Wiki 仅纳入 compositional/inference 型，并且恰有两个支持标题、全部支持句可读、非 yes/no 标准答案仅在其中一个标题的标注句里出现。该标题记为答案侧，另一个记为桥接侧。其余题仍参与全标题/句统计，角色指标不计入分母。结果回传角色指标样本量。2Wiki 原始资料还有关系三元组 evidences，本轮用的 FlashRAG 快照未提供该字段。
- 标准答案字符串命中使用规范化词边界，在单篇检索文档的标题和正文中匹配。与旧 p0_diag 的整段子串命中略有口径差异。

## 固定查询预算

每个 search 调用可以包含多条 query_list。按日志顺序将调用、返回块和块内标题配对。一条查询对应一个结果块，沿用 P0 的 top-3。同一调用里的查询按 query_list 顺序计数，这个顺序用于离线截断。实际执行时模型一次看到该调用内的整批结果。主预算为前 2 条查询，另报前 1、3、5 条。每个截断点只使用原轨迹已经看到的结果。自然停止或查询不足时沿用其已有结果，零查询算零覆盖；已知请求错误占一次查询但返回空结果；块数错位、标签或协议无法解析的题从两臂的共同配对中剔除并计数。单独报至少到达该查询预算的比例与两轮都到达第 2 条的辅助对照。

另报第一条查询、整个首次调用、后续新增支持标题、最终覆盖。在符合桥接角色条件且两轮都发起过查询、又都在第一条漏掉桥接标题的配对题中，探索第 3 条查询预算内是否找到桥接标题。这个子群由观察到的行为定义，既可能受继续次数影响，也可能受查询质量影响。

## 已冻结的判定

质量条件按 HotpotQA、2Wiki 各自判断。原评测 parquet 的样本数必须等于 7,405 / 12,576，第 1、3 轮两个 dump 各自总数须匹配，且至少 95% 的预期题在两轮可解析并成功配对。配对题中至少 90% 要匹配到支持标题，否则返回 INVALID_INPUT。

主要指标是前 2 条查询内全部标注支持标题均命中的逐题配对率。每套数据集计算第 3 轮减第 1 轮，再对两套数据集等权平均。对每套数据集重采样问题、按配对保留两轮结果，5,000 次分层 bootstrap，种子 20261117。区间只刻画这些题的抽样不确定性。

| 判定 | 条件与动作 |
| --- | --- |
| GO_PREFIX_REPLAY | 等权差 ≤ −2 个百分点、95% CI 上界 < 0，且两个数据集点估计均为负。家服据此设计受控同前缀回放。 |
| NO_MATERIAL_SUPPORT_LOSS | 等权差的 95% CI 下界 > −2 个百分点，且精确支持句没有下述明显反向信号。暂停按标题覆盖驱动的桥接恢复路径。 |
| REVIEW_TITLE_SENTENCE_DISAGREEMENT | 标题端点排除 −2 个百分点退化，但同预算完整支持句等权差 ≤ −2 个百分点且 95% CI 上界 < 0。先查文档切片、标题覆盖与事实覆盖的差异。 |
| INCONCLUSIVE | 其余有效结果。家服检查样本与分层后再决定。 |
| INVALID_INPUT | 输入或配对质量未达要求。先修复解析、题目映射或输入文件。 |

GO 时，如果两套数据集各有至少 100 道共同首查漏失且角色可定的题、该子群第 3 条查询预算内的桥接找回率等权下降至少 2 个百分点、95% CI 上界 < 0 且两集点估计均为负，优先回放桥接恢复。否则先定位首次查询、自然停止与后续质量。任何判定都只说明下一项诊断的选择；不自动发起训练或 GPU 任务。
