# RSI 配对环境推理预实验

版本 2，冻结 Qwen2.5-7B-Instruct。同一模型及解码配置下，测量自主查证与直接看到真实证据后的作答差距。

## 研究问题

当模型在只读工具环境中选错行动时，失败可能来自找不到当前决策所需的事实，也可能来自看到充分证据后仍然无法应用规则。两种失败需要不同的后续训练任务。这里检验在可控环境中，两类失败是否有足够多的实例、是否能从工具轨迹和对照条件中复核。

后续方法候选是按失败类型选择下一轮配对任务。获取失败增加查证路径和隐藏条件的变化，使用失败增加基于已见证据的规则应用练习。评估时比较这种生成策略、普通难度匹配和固定任务池的增益。本轮只运行冻结模型并检查诊断是否可用。

## 配对环境与对照

- 每个目标样本包含两个环境，题面、规则、订单、SKU 和其余库存字段都相同。只改变一个 SKU 的 `on_hand`，使两个环境的正确行动分别为 A 和 B。世界顺序按种子决定。
- 开发组用单 SKU 和先查订单再查库存。留出组用套件库存和扣除预留量两个模板。留出表示本轮独立的任务模板，题面和生成器均可在本公开仓库中检查。
- 对照题同样含一个隐蔽的库存变化，公开的调度覆盖规则使两个世界的答案都由题面直接决定。检查两边正确率和发生查询的样本比例。
- 工具只查询当前环境的合成记录，支持按订单号和 SKU 精确查询。未知 ID 返回空记录，消耗一次预算。服务端每次完成请求共给 256 个生成 token，自主每个世界最多执行四次查询。

## 两种推理条件

1. 自主查询。模型对两个环境共享同一可见历史时只生成一次，运行同一个工具调用。只有工具返回确实不同才分别生成后缀。模型若在分叉前作答，两边采用同一个答案。
2. 直接提供证据（oracle）。对目标题，把固定查询计划按顺序作为助手调用和原始工具返回加入各世界的消息历史。复用自主条件的系统提示、工具接口和解码。在证据后追加不含事实的结束查询指令，用一次生成作答。额外尝试调用工具记为单独的格式状态。消息没有标准答案和世界标签。

每个目标样本记录两个条件的双世界正确与单世界正确、有效作答数、是否观察到变化、每个世界是否已经获得足够证据、工具执行数及推理调用和 token 开销。套件题查到订单和任一缺货商品即可充分支持 B，支持 A 则需要确认全部商品。oracle 使用完整固定查询计划。

## 判读与下一轮决策

- 获取失败证据来自自主双世界未通过、错误世界证据不足、且 oracle 两个世界都答对的样本。按是否见过变化的库存记录再分。若自主耗尽查询预算，逐条记录里可区分预算耗尽和有效作答。
- 证据使用失败指自主条件两边均给出有效答案，且每个答错的世界在作答前已见充分证据。进一步检查 oracle 是否答对，了解固定顺序的证据重放能否改善表现。
- 证据不足和已见证据却答错同时发生时，保留混合标签。单列输出格式、输出截断、获得证据后仍耗尽预算、oracle 无有效答案和 oracle 答错。逐对记录保留状态与证据标记，供抽样核验。
- 先看两个留出模板各自的 oracle 双世界正确率、有效作答、两种失败计数及对照题的多余查证。若 oracle 本身常失败，先检查提示、答案协议和模型能力。若两类失败在留出模板都能复核且有足够样本，再立项比较下一轮的任务生成策略。
- 两种条件的历史、作答提示和开销有差异，差值用于诊断，无法单独识别工具返回内容的作用。跨模板、跨模型的稳定性及训练收益需要单独验证。
