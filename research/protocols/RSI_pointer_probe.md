# RSI 订单引用定位与学习试点准入

随后将是否修复了一次可定位的检索动作作为首要评估。在同一冻结 7B、温度 0、每次 256 token、每世界四条查询和批量接口下比较。独立种子基数 20261121，原订单改版结构 30 对作参考。批准状态列表和最高版本号列表是两个新结构，各 60 对，正确引用在列表中的位置由种子决定。每对的世界仅改变正确订单所需 SKU 的库存值，正确路线随之翻转。

所有条件预置真实票据查询及原始返回，从相同根记录开始。预置的每条查询照常扣减每世界预算。系统规则和查询返回沿用正式批量接口。

| 条件 | 票据返回后的操作 |
| --- | --- |
| autonomous | 继续自主查证，剩三条查询预算 |
| grounded | 加一条通用指令，只用已见 ID、先沿引用查询，再自主查证，剩三条 |
| force_current | 预置当前或批准版本的真实查询返回，再自主查证，剩两条 |
| force_archived | 预置已废弃版本的真实查询返回，再自主查证，剩两条 |

两个预置臂的预算、记录字段和可见历史轮数匹配；不会预置库存或答案。旧订单的结果属真实无关记录，模型仍可回到正确路径。字段语义不同正是这次检索干预的内容。四臂执行次序按样本交错。只有相同的预置消息可用于两个世界，否则运行失败。读到决定性库存返回之后才分叉。

终止评分接受唯一合法答案标签及可选末尾句号，也接受整条生成恰好为 A 或 B。截断、尾随额外文本和工具混写单独处理。单独记录首行动及被拒的原始输出以追踪格式问题。旧协议继续使用各自的评分规则。

每个家族报告首个自主动作是否查当前或已废弃版本、空记录查询、实际取得决定性库存、有效对数、双世界正确数、开销和逐对胜负。训练候选只考虑 grounded 两世界均有效但配对失败、且至少一侧未取得决定性库存，同时 force_current 两世界都答对而 force_archived 两世界均有效但配对失败的样本。格式错误不进入该计数。

两个新结构都满足以下工程条件后，再排期获取失败单线的学习试点：

- force_current 相对 force_archived 的净胜数至少 10/60。
- 通用提示之后仍有至少 6/60 对符合上述训练候选条件。

旧结构用于检查与既有现象的连续性。若通用提示已达到接近强制查证的表现，优先保留该推理基线。若选择正确引用仍无法带来取证或正确作答，继续定位下游错误。本轮指标只用于筛选学习候选；训练计划应在独立留出结构上比较真实失败类型分配与同预算、同难度的打乱标签分配。
