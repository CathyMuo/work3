# RSI 配对环境 oracle 校准协议

版本 rsi_calibration_v1。使用冻结的 Qwen2.5-7B-Instruct，在同一组配对任务上定位 v2 直接给证据条件的低正确率，同时记录自主查询在工具接口处的失败。校准和确认阶段均只做推理。

## 样本及固定参数

诊断阶段使用 v2 原种子 20261117，并在代码中固定合成题下标。

| 模板 | 目标对 | 对照对 |
| --- | --- | --- |
| 套件库存 | 6 对原先格式失败，3 对原先自主两边正确，3 对原先拿到充分证据仍答错 | 2 对原先格式失败，2 对原先正确 |
| 扣预留量 | 6 对在 B 世界账面库存已不足，6 对账面够但扣预留后不足 | 4 对有公开调度覆盖规则 |

各目标对在四个直接给证据条件下都测两个世界，共 192 次最终作答。相同 32 对另跑 v2 自主条件。原先结果只用于选样，回放时重新请求模型。这个样本按已知现象选取，汇总比例仅用于诊断。

固定解码温度 0、每次生成最多 256 token、自主每世界最多四次查询、原模型与 tokenizer。自主沿用 v2 的共享前缀、分叉条件和查询解析。拒绝输出时保存实际生成、停止原因、解析原因、当时的对话历史，以及已有查询数。分叉前的一次失败对应两个世界，共享记录只计一次生成。若重现主要是一次调用提交多条查询，再决定是否另开接口放宽对照。

## 四种直接证据条件

| 条件 | 证据呈现 | 用于最终回答的指令 |
| --- | --- | --- |
| tool_direct | 预填助手工具调用和 tool 返回 | v2 原指令 |
| tool_compare | 同样的工具消息 | 先列原始数值，按题意比较，末行给 A/B 标签 |
| inline_direct | 将同序查询和原样 JSON 放在题目后的用户消息 | v2 原指令 |
| inline_compare | 同样的用户消息证据 | 先列原始数值，按题意比较，末行给 A/B 标签 |

所有条件的题面、证据键、证据 JSON 和顺序一致。脚本只给原始字段和统一的作答指令。两个世界各自读对应的原始返回。比较提示请模型自行计算。所有条件沿用同一末行答案解析。工具调用若出现在作答阶段，标记为 unexpected_tool。报告每模板的双世界正确数、A/B 各自正确数、相同答案数、有效答案数、相对原版的逐对改善与回退、实际生成和提示 token 数。题面和事实固定，呈现方式和作答指令会改变上下文及实际生成长度。

## 新种子确认

家服据诊断结果选定一个条件并固定后，才进入新的种子 20261118，每模板 30 对目标题，无对照，共 120 次最终作答。工程门槛要求两个模板分别达到：

- 有效答案至少 57/60。
- 双世界均正确至少 21/30。
- B 世界至少 24/30 正确。

门槛用于判断直接证据条件能否继续作为诊断工具。通过后，下一轮仍需在更有区分度的检索路径上确认获取失败和使用失败是否都可复核，再安排训练对照。若未通过，家服复核真实自主工具历史与预填历史的差异。
